# 📰 full_blog_site

A modern and responsive full-stack blog application built with **React**, **TypeScript**, **Tailwind CSS**, and **Express.js**.  
This project allows users to create, edit, and delete posts with an integrated authentication system and elegant dark mode support.

---

## 🚀 Features
- 🖋️ Create, Edit, and Delete blog posts  
- 🔐 Secure Login System  
- 🌗 Dark / Light Mode toggle  
- 💨 Fast and responsive UI built with Tailwind CSS  
- ⚙️ Backend powered by Express.js  

---

## 🛠️ Tech Stack
**Frontend:** React, TypeScript, Tailwind CSS  
**Backend:** Express.js  

---

## 📦 Installation

```bash
# Clone this repository
git clone https://github.com/your-username/full_blog_site.git

# Go to the project folder
cd full_blog_site

# Install dependencies
npm install

# Run the development server
npm run dev
